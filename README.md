성도는 **이름**과 관리자가 나눠 준 **8자리 입장 코드**로 들어갑니다.
대전만 참여할 때는 코드 없이 이름만 적고 TV의 QR을 찍으면 됩니다.

## 이름의 뜻

‘새김’은 히브리서 8:10의 *ἐπιγράψω*(에피그라포, 새기다·기록하다)에서 왔습니다.
붉은 도장 안에 펼친 말씀을 담은 로고는, 말씀이 마음에 도장처럼 새겨지기를 바라는 마음입니다.

## 암송은 이렇게 합니다

듀오링고처럼 쉬운 단계에서 어려운 단계로 한 걸음씩 올라갑니다.

1. **읽고 듣기** — 소리 내어 읽고, 낭독을 듣습니다
2. **순서 맞추기** — 섞인 말씀 조각을 순서대로 놓습니다
3. **빈칸 채우기** — 빠진 단어를 채웁니다
4. **초성 보고 쓰기** — `ㄱㄹㄴ ㅇㅈ ㄱㄹㅅㄷㄲㅅ`처럼 초성만 보고 씁니다
5. **통째로 쓰기** — 장절만 보고 말씀 전체를 씁니다
6. **복습** — 외운 말씀이 1일 · 3일 · 7일 · 14일 · 30일 뒤에 다시 찾아옵니다

- 다 외운 뒤 **“이 말씀이 나에게 하는 한 줄”**을 적어 묵상으로 이어 갑니다.
- 코스를 모두 마치면 교회 이름이 들어간 **수료증**을 받습니다.
- **쉬운 모드**를 켜면 타자 대신 골라서 맞힙니다. 어르신도 함께하실 수 있습니다.
- 정답 규칙은 **엄격 · 보통 · 느슨** 가운데 고릅니다. 띄어쓰기와 문장부호는 보지 않습니다.

## TV 말씀 대전

TV에 QR과 6자리 방 코드가 뜨면, 핸드폰으로 들어와 함께 겨룹니다. 개인전과 사랑방 팀전 모두 됩니다.

| 대전 방식 | | 대전 테마 | |
|---|---|---|---|
| 스피드 빈칸 | 빨리 맞힐수록 높은 점수 | 여리고 성벽 | 정답이 쌓이면 성벽이 무너집니다 |
| 순서 레이스 | 말씀 조각 순서 맞추기 | 다윗과 골리앗 | 모두의 정답으로 거인을 쓰러뜨립니다 |
| 주소 맞히기 | 본문 보고 장절 찾기 | 홍해 건너기 | 맞힐수록 바다 길을 달려갑니다 |
| 통째로 쓰기 | 정확도와 시간 합산 | 갈멜산 제단 | 팀마다 제단을 쌓고 불이 내립니다 |
| 서바이벌 | 틀리면 탈락 | 노아의 방주 | 살아남은 사람이 방주에 오릅니다 |
| 사랑방 릴레이 | 팀원이 한 조각씩 이어 쓰기 | 아케이드 | 네온 게임쇼 분위기 |

리모컨이나 키보드의 **스페이스 / → 키**로 다음 문제로 넘어갑니다.

## 관리자가 할 수 있는 일

- **코스와 말씀** — 샘플 양식 받기, 엑셀 업로드(미리 보기 후 저장), 기본 코스 넣기, 본문 고치기
- **사용자와 코드** — 한 명 또는 여러 명 한꺼번에 코드 발급, 코드 분실 시 다시 발급(기록은 그대로), 코드 목록 엑셀
- **팀** — 사랑방 이름과 색 정하기
- **진도 리포트** — 사람별 · 팀별 진도를 보고 엑셀로 받기
- **관리자** — 함께 섬길 관리자를 추가하고 10자리 관리자 코드 발급, 필요 없으면 지우기
- **이번 주 암송** — 고른 말씀을 모든 사용자 홈 맨 위에 올리기
- **환경 설정** — 테마 5가지(새벽 · 감람산 · 성막 · 광야 · 별밤), 말씀 글꼴, 화면 글꼴, 글자 크기, 배경 사진, 교회 로고, TV 배경, 사용할 학습 단계, 하루 새 구절 수, 복습 간격, 낭독 속도, 정답 규칙, 대전 기본값

### 처음 시작할 때

1. 관리자 화면에 최초 관리자 코드(또는 최고 관리자 구글 계정)로 들어갑니다.
2. **코스와 말씀 → 기본 코스 넣기**로 「주제별 성경암송 180구절」을 넣습니다. (제자의 도 72구절, 제자 삼는 자 45구절도 들어 있습니다)
3. **팀**에서 사랑방을 만듭니다.
4. **사용자와 코드 → 여러 명 추가**에 `이름, 팀이름`을 한 줄씩 붙여 넣고, 코드 목록을 엑셀로 받아 안내합니다.
5. **환경 설정**에서 우리 교회에 맞게 꾸미고 저장합니다.

### 엑셀 양식

| 코스 | 번호 | 주제 | 장절 | 본문 | 메모(선택) |
|---|---|---|---|---|---|
| 12월 성탄 암송 | 1 | 구주의 탄생 | 눅 2:11 | 오늘 다윗의 동네에 너희를 위하여 구주가 나셨으니 곧 그리스도 주시니라 | |

같은 코스 이름끼리 한 묶음이 되며, 이미 있는 코스 이름으로 올리면 그 코스를 새 내용으로 바꿉니다.

## 기술 정보

- 순수 HTML · CSS · JavaScript, GitHub Pages로 배포
- Firebase Firestore(서울) 실시간 데이터 · 익명 로그인 · 관리자 코드 / 구글 로그인
- 보안 규칙은 [`firestore.rules`](firestore.rules)에 있습니다
- Firebase · 엑셀 · QR 도구를 `vendor/`에 담아 외부 CDN 없이 동작합니다 (글꼴만 Google Fonts)
- 홈 화면 설치(PWA)와 오프라인 기본 동작 지원
- 화면 점검용 가상 모드: 주소 끝에 `?mock` (관리자는 `?mock=admin`) — 실제 데이터에 손대지 않습니다

```
saegim/
├─ index.html      사용자 앱
├─ admin.html      관리자
├─ tv.html         TV 대전
├─ css/            디자인 (공용 · 앱 · 관리자 · TV)
├─ js/             core.js(공용) · app.js · admin.js · tv.js
├─ data/           기본 코스 (개역개정 297구절)
├─ assets/         엑셀 업로드 샘플 양식
├─ icons/          앱 아이콘
└─ vendor/         Firebase · SheetJS · QR 생성기
```
