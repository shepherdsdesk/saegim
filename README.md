# 새김 INSCRIBE

말씀을 마음에 새기는 성경 암송 앱입니다. 만든 곳: **AI목양지원센터**

> 그들의 마음에 이것을 기록하리라 (히브리서 8:10)

## 화면 세 가지

| 주소 | 누가 | 하는 일 |
|---|---|---|
| `index.html` | 사용자 (핸드폰·태블릿·PC) | 이름 + 8자리 입장 코드로 들어가서 암송, 복습, 대전 참여, 내 기록 |
| `admin.html` | 관리자 (bear4jesus@gmail.com 구글 계정만) | 코스·말씀 엑셀 업로드, 사용자 코드 발급, 팀, 진도 리포트, 환경 설정 |
| `tv.html` | TV 화면 | 대전 방 만들기 → QR·방 코드 → 실시간 대전 |

## 처음 한 번 할 일

1. `admin.html`에 들어가 구글 계정으로 로그인합니다.
2. **코스와 말씀 → 기본 코스 넣기**에서 「주제별 성경암송 180구절」(개역개정)을 넣습니다. 제자의 도 72구절, 제자 삼는 자 45구절도 함께 넣을 수 있습니다.
3. **팀**에서 사랑방 이름으로 팀을 만듭니다 (팀 대항전에 필요).
4. **사용자와 코드 → 여러 명 추가**에 `이름, 팀이름`을 한 줄씩 붙여 넣고, **코드 목록 받기**로 엑셀을 받아 안내합니다.
5. **환경 설정**에서 테마·글꼴·글자 크기·배경 사진·교회 로고·학습 단계·정답 규칙·대전 기본값을 정하고 저장합니다.

## 암송 단계 (듀오링고식)

읽고 듣기 → 순서 맞추기 → 빈칸 채우기 → 초성 보고 쓰기 → 통째로 쓰기 → 복습(1·3·7·14·30일 간격)

- **쉬운 모드**: 타자 대신 골라서 맞히기 (어르신용, 사용자가 내 기록에서 켜고 끔)
- **정답 규칙**: 엄격 / 보통 / 느슨 (코스마다, 대전마다 따로 정할 수 있음)
- 외운 뒤 **나의 한 줄** 묵상 기록, 코스를 마치면 **수료증** 이미지 내려받기

## 대전

방식 6가지: 스피드 빈칸, 순서 레이스, 주소 맞히기, 통째로 쓰기, 서바이벌, 사랑방 릴레이
테마 6가지: 여리고 성벽, 다윗과 골리앗, 홍해 건너기, 갈멜산 제단, 노아의 방주, 아케이드
개인전·팀전 모두 가능. 리모컨·키보드의 스페이스/→ 키로 다음 문제로 넘어갑니다.

## 기술 정보

- Firebase 프로젝트: `saegim-inscribe` (Firestore 서울, 익명 로그인 + 관리자 구글 로그인)
- 보안 규칙: `firestore.rules` (콘솔에 이미 적용됨)
- 외부 CDN 없이 `vendor/` 폴더에 Firebase·엑셀·QR 도구를 넣어 두었습니다 (글꼴만 Google Fonts).
- 홈 화면 설치(PWA) 지원: `manifest.webmanifest`, `sw.js`
- 화면 점검용 가상 모드: 주소 끝에 `?mock` (관리자는 `?mock=admin`) — 실제 데이터에 손대지 않습니다.

## 배포 (GitHub Pages)

`https://shepherdsdesk.github.io/saegim/` 에서 열립니다. 이 주소는 Firebase 승인 도메인에 이미 들어가 있습니다.
